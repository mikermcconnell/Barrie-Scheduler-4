1Table gets the screen. One compact top row; the table fills the window with a fixed header and Block column.
2Stages as a control with live status (✓, connections met, edit count), not a second stepper.
3Blocks visible. Hover a row to light up its whole block (coloured bar). Switch View → Blocks for one lane per bus.
4Colour for exceptions only. Normal values are plain; red = short layover, amber = recovery % or headway off target, outline = your edit.
5Inspector drawer. Click a row; details slide in over the table.
6Issues pill. Click to list issues and jump to the row.
7Connection markers where they matter. Full ✓/✕ in Connections; elsewhere only misses.
8Show changes against the generated schedule (old value struck through).
9Hour separators for scanning a long day.
10Bigger edit targets with a keyboard hint. Click a DEP or R cell in Tweaks.
11Editor parity. Trip times and recovery are editable here; add/remove trip and block swap would come from the existing editor.
