# Artifacts

`docs/artifacts/` stores supporting files that may be useful for reference, demos, or examples, but are **not default repository context**.

Typical contents:
- exported reference files such as PDFs or DOCX files
- presentation notes
- example input files
- point-in-time analysis attachments or companion documents

## How to use this folder

- Start with `AGENTS.md` and `docs/CONTEXT_INDEX.md` first.
- Open artifacts only when a task explicitly needs that file.
- Do not treat files here as durable source of truth for current implementation behavior.

## Subfolders

- `reference/` - supporting reference documents
- `presentations/` - demo or presentation materials
- `analysis/` - attached analysis notes and companion exports
- `examples/` - sample inputs or example files
