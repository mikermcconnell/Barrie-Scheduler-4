# Street Design Studio — first-draft usage

The workspace is off by default. Set `VITE_FEATURE_ANALYTICS_STREET_DESIGN_STUDIO=true`, run the app, sign in with internal Planning Data access, and open `#planning/street-design-studio` (or select its Planning Data card). This is an evaluation draft, not a construction or compliance tool.

1. The initial project is a **fictional** 160 m corridor. Clean plan needs no map service. Street map uses OpenFreeMap; aerial is shown only when an approved XYZ source is configured.
2. To start another project, use **New project** in the inspector. Enter a name and WGS84 longitude/latitude. The 40 m starter alignment and bands are illustrative assumptions, not observed site conditions. Switch to **Street map**, select **Street**, click two or more road points, then **Finish**. Each click snaps to a mapped road centreline within 12 screen pixels when available; the **ROAD SNAP** ring confirms it. Hold Shift for a free point. Click additional points around bends: this draft snaps individual control points, but does not automatically route between them. **START** and **END** identify the current alignment. Escape cancels an unfinished trace. If a new alignment would strand an existing stop, crossing, or dimension, Finish rejects it and keeps the draft so you can extend it.
3. Set the **Concept envelope** to a known or explicitly estimated total width in metres. Review the proportional band-width preview, then **Apply overall width**. The mapped road stroke is cartographic, not a measured edge, so this does not automatically fit real pavement. Select a band on the map or in **Entities** to edit a single width. The side envelope is locked: increasing one width requires an explicit **Transfer width** from a donor. Select parking to replace it with a 0.60 m buffer plus the remaining cycle band. Add a width dimension from the selected band.
4. Use Crossing, Bus stop, or Tree, then click near the alignment. Stops remain anchored to their boundary/station. Reference line and area tools accept a sequence of map clicks and a Finish action. Imported WGS84 GeoJSON reference data retains unknown export permission, so derived exports are blocked until rights are assessed.
5. Freeze Existing into a baseline before creating an alternative. Alternatives pin that baseline. Toggle the scenario and baseline outline without resetting the map camera. Undo/redo applies to the selected scenario.
6. The save indicator reports IndexedDB writes **on this device**. Export native JSON as a portable backup. Native import creates a new local copy. SVG/PDF are vector A3 concept sheets; GeoJSON is derived geographic interchange, not a full-fidelity project file.

Known first-draft gaps: no drag handles or automatic road-network routing between snapped points, no road-edge/width extraction, no band reorder/delete, limited reference inspection, no true cross-section view, no authenticated cloud saving, no tested real aerial provider, and no engineering validation. Consult `IMPLEMENTATION_STATUS.md` and `VERIFICATION_REPORT.md` before using output for decisions.
