# Development notes

- Use the repository's npm lockfile. Node 22.17.0 was used for this run. `npm install` resolves existing dependencies; the added direct packages are exact-pinned in `package.json`.
- `npm run dev` starts Vite (the observed local server used port 3008). Set `VITE_FEATURE_ANALYTICS_STREET_DESIGN_STUDIO=true` before starting to expose the gated workspace to internal profiles.
- `npx vitest run tests/streetDesignStudio.domain.test.ts` runs focused numerical tests. `npm run typecheck`, `npx eslint components/Analytics/StreetDesignStudioWorkspace.tsx utils/street-design-studio tests/streetDesignStudio.domain.test.ts`, `npm run build`, and `npm run docs:check` are relevant checks. The repository-wide `npm run lint` currently fails outside this module; see `VERIFICATION_REPORT.md`.
- Browser harness: run `npx vite --host 127.0.0.1`, then `node tests/street-studio/smoke.mjs`, `node tests/street-studio/context-smoke.mjs`, `node tests/street-studio/new-project-smoke.mjs`, or `node tests/street-studio/export-smoke.mjs`. Scripts currently target the observed port 3008, so adjust the base URL if Vite chooses another port. The harness mounts the actual workspace component without Firebase auth; it does **not** prove the signed-in route.
- `domain.ts` owns commands and native schema; `geometry.ts` compiles a local-metre scene; `export.ts` makes SVG/PDF and WGS84 GeoJSON from that scene; `storage.ts` owns atomic IndexedDB writes. MapLibre is a derived view, never the project store.
- Street style configuration: `VITE_STREET_STUDIO_STYLE_URL` defaults to OpenFreeMap. Additional style hosts must be declared with `VITE_STREET_STUDIO_ALLOWED_STYLE_HOSTS`. Aerial requires `VITE_STREET_STUDIO_XYZ_URL`, `VITE_STREET_STUDIO_XYZ_ATTRIBUTION`, and an allowed hostname in `VITE_STREET_STUDIO_ALLOWED_IMAGERY_HOSTS`. Only public HTTPS XYZ URLs without query tokens are accepted. Obtain provider permission separately; this code does not grant imagery rights.
- Feature remains default-off while P0 acceptance failures remain. Do not connect cloud storage without a server-authorized adapter and a Firestore rules/indexes review.
