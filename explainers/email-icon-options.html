Daily email: new icon set options

Six new icon styles, each shown in the real email header and KPI row. The current style is at the top for comparison. Every option can go through the existing scripts/generate-email-icons.mjs pipeline (SVG drawn once, saved as PNG, sent as an inline attachment), so all of them work in Gmail and Outlook. Option F needs no images at all.

My pick: B (Soft tile) if you want icons to stay a visual anchor: it is the modern dashboard look (Stripe, Linear, Notion) and survives small screens well. E (Inline label) if you want the cards to feel calmer and more like a report than a dashboard. F (No icons) is the most "editorial" and removes all image attachments, but the cards lose quick scanning cues.

Note on D (Data marks): the gauge and bars are fixed drawings, not live values. We could make the OTP ring show the real percentage, but that needs one PNG per value band (for example every 5%), so I'd treat that as a later step.
