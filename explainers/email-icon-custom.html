Daily email: custom illustrated icons

An original set drawn for this report: a bus, an alarm clock with an on-time check, riders, a route to a pin, and a stopwatch with the dwell time shaded. Each icon uses the colour of its KPI card, with amber as a shared second colour. Gradients and shadows are fine here, because the generator turns each icon into a PNG before it goes into the email. Each style is shown large, at email size, and in the real email layout.

Fit with email: each icon would be saved as a PNG at 3x (about 4–10 KB each, 5 icons per email) and attached the same way the current icons are. No new email code.
Dark mode: style 1 sits on a white tile in the header, and style 3 has its own solid tile, so both stay readable if a mail app darkens the email. Style 2's tinted circle is part of the image, so it is safe too.
